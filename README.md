# habitfy

Overview
Habitfy is a watchOS application that tracks and manages habits. It also includes a simple Python backend for data handling.

Getting Started
Download the Project:

Download the ZIP.

Uncompress the downloaded file.

Open a terminal and navigate into the habitfy folder that was unzipped.

Start the Backend Server:

In your terminal, move into the backend directory:
cd backend

Run the backend server:
python app.py

Make sure the backend stays running before launching the watch app in Xcode.

Launch the Frontend:

Open the habitfy project in Xcode.

Select a watchOS simulator (e.g., Apple Watch Series 6) from Xcode’s device list.

Click Run to start the simulation.
